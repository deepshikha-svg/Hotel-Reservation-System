 Hotel-Reservation-System
 The main idea behind this project is to create a simple system that makes basic hotel room booking and customer management easier.Through this program, users can check room availability, book rooms, enter customer details, manage booking information, and calculate the total bill.
The project uses structures, arrays, loops, conditional statements, and functions to perform different hotel management operations.
Key Features
Room Management: Maintains room availability and booking status.
Customer Management: Stores customer details, including customer ID, name, and phone number.
Room Reservation: Allows users to book available rooms.
Booking Information: Keeps track of room numbers, customer IDs, and duration of stay.
Bill Calculation: Calculates the total bill based on the number of days of stay.
Menu-Driven Interface: Provides an easy-to-use interface for performing different operations.

 Technologies Used
 Programming Language: C
 Concepts: Structures, Arrays, Loops, Conditional Statements, and Functions.
 Objective
The main objective of this project is to understand and implement fundamental C programming concepts by developing a practical hotel management application. It demonstrates how programming can be used to manage customer records, room reservations, and billing operations.
